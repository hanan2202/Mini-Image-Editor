# Mini Image-Editor
GUI-based image editor with basic image manipulation and editing functionalities.
Some of the functions do not work properly.

**Features**
- Crop images
- Rotate images
- Resize and scale images
- Translate images
- Flip images horizontally and vertically
- Freehand drawing
- Add circles and text to images

**Repository Contents**
1. mini_image_editor.py - Python source code
2. Materials - Image resources and icons required when running the source code

**Standalone Application**
A standalone Windows executable is available for users who want to try the application without running the Python source code.
Link: 

How to Run:
1. Download MiniImageEditor.exe from the latest release.
2. Locate the downloaded file.
3. Double-click the executable to launch the application.

No separate Python installation is required.
Note: Windows may display a security warning when opening the executable because it is not digitally signed.

**Running from Source**
To run the application using the Python source code:
1. Download or clone this repository.
2. Make sure the Materials/ folder is in the same directory as mini_image_editor.py.
3. Install the required Python packages.
4. Run mini_image_editor.py.

**Technologies Used**
- Python
- Tkinter
- Pillow
- OpenCV
- NumPy
